# leetcode-python

A personal collection of LeetCode and interview problem solutions, primarily in Python.

## Layout

Most Python solutions live at the repository root and use the problem number and title in the filename. Related practice collections are grouped in directories such as `google/`, `amazon/`, `karat/`, and `codility/`. Java solutions are in `java/`.

```text
001-Two_Sum.py
google/
amazon/
karat/
codility/
java/
templates/solution.py
```

## Add a solution

Copy `templates/solution.py` to the repository root (or the relevant topic directory), then name it with the problem number and title. Replace the class method signature with the one required by LeetCode. Include the problem link, approach, and time and space complexity in the file.

Python solutions use the standard library unless a problem needs an additional dependency.
